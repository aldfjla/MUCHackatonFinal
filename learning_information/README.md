# learning_information

Everything we learned about the Tacto Negotiation Arena challenge, collected on 2026-10-10. Read-only copies; nothing here contains a key.
Collected without opening any practice session (only free GET calls). Data and docs are CC BY 4.0, kit code MIT.

| Folder | What is in it |
|---|---|
| `01_brief_and_rules/` | Tacto's brief, API docs (`api.md`), submission guide, kit README |
| `02_data_package/` | The buyer's data: CSV tables (`data/`), contracts, correspondence, `facts.json` (every citable ID), company description. `world.sqlite` (same data) left out to save space |
| `03_practice_cases/` | All 19 practice case files (JSON) plus `INDEX.md`; 10 are hosted |
| `04_sandbox_cases/` | Sandbox cases D01, D02 (free to play, not counted in the quota) |
| `05_arena_website/` | Home page and FAQ as text (scoring, local vs deployed, token costs, a worked replay) |
| `06_team_status/` | Our quota and best scores (`me.json`), practice leaderboard snapshot |

The final's hidden cases and the Sunday 08:00 release are not here yet; `GET /v1/data` will list the release once it is public.
